# Spotify-login-page-clone
A simple and visually faithful clone of the Spotify interface, mimicking the registration, login, and security code verification process.

## 🚀 Key Features
- **Multi-page Navigation:** Smooth transitions between the landing page, login page, and 6-digit code verification screen via interactive buttons and arrows.
- **User Interface:** Carefully styled based on Spotify's design system (centered 324px container, custom typography, and smooth hover effects).
- **Input Validation:** Code input fields are strictly restricted to numeric values.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, custom styling)
- JS
